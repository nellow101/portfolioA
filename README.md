# Portfolio & Enterprise Web Applications

A high-performance, dark-themed portfolio and showcase built with **ASP.NET Core MVC**, **Tailwind CSS**, and **SQL Server**. Designed to highlight full-stack software development capabilities, responsive UI engineering, and enterprise-grade backend architecture.

## 🚀 Live Projects & Demos

* **IT Helpdesk Ticketing System (ITSM):** [Live Demo](http://nellogroupitticketing.runasp.net) — Full-stack enterprise support portal featuring role-based access control (Employee, Technician, Admin), automated tracking, and robust database logging.
* **Digital Credit Book & Transport System:** Ledger software for secure customer credit tracking combined with a courier/bakkie dispatch management routing module.

* **Front-End:** HTML5, CSS3, JavaScript, Tailwind CSS, FontAwesome
* **Database & Cloud:** Microsoft SQL Server, Azure SQL, MonsterASP Hosting
* **Infrastructure & Tooling:** Git/GitHub, Visual Studio 2022, Windows Server, Active Directory, TCP/IP, DNS/DHCP
